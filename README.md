# 📻 RP2040 Receiver Control

**RP2040 Receiver Control** — это легковесное и отзывчивое десктопное приложение для Windows, предназначенное для управления SDR-приёмником на базе микроконтроллера **RP2040** по CAT-протоколу через COM-порт. Приложение разработано на **C++17** с использованием **Qt6 Widgets** и глубоко интегрировано с Windows API для достижения максимальной производительности и минимальных задержек.

---

## ✨ Ключевые возможности

### 🔌 Соединение и CAT-интерфейс
* **Управление COM-портами:** Автоопределение доступных портов (`COM1`–`COM256`).
* **Гибкая скорость:** Поддержка скоростей 9600, 19200, 38400, 57600 и 115200 (по умолчанию).
* **Синхронизация:** Автоматический опрос состояния приёмника (`FA`, `MD`, `SL`, `SH`, `NR`, `NT`) при подключении и обновлении.
* **Диагностика:** Встроенный журнал TX/RX команд с временными метками, функциями копирования и очистки лога.

### 🎛️ Управление частотой и режимами
* **Интуитивный VFO:** Индикатор частоты с изменением значений колесом мыши (клик по конкретной цифре выбирает шаг изменения).
* **Прямой ввод:** Быстрая установка частоты через текстовое поле (диапазон `1` – `99 999 999 Гц`).
* **Быстрые пресеты:** Переключение КВ-диапазонов в один клик: `160м`, `80м`, `40м`, `20м`, `17м`, `15м`, `12м`, `10м`.
* **Модуляция:** Поддержка режимов `LSB`, `USB`, `CW`, `FM`, `AM`.

### 🎚️ Обработка сигнала и DSP
* **Полоса пропускания:** Раздельный слайдер нижнего и верхнего срезов (`0`–`5000 Гц`) + поля прямого ввода.
* **Пресеты фильтра:** Быстрый выбор полосы: *Узкая* (300–2200 Гц), *Нормальная* (100–2700 Гц), *Широкая* (0–3100 Гц).
* **Шумоподавление:** Быстрое включение/выключение цифрового шумоподавления (`NR`) и режекторного фильтра (`NT`).

### 📊 Аудио и Анализатор спектра
* **Низкоуровневый звук:** Захват через `waveIn` и воспроизведение через `waveOut` (WinMM API).
* **FFT Анализатор:** Спектроанализатор реального времени с размером блока **8192** и сглаживанием EMA (экспоненциальное скользящее среднее).
* **Запись эфира:** Встроенный инструмент записи аудиопотока в формат `.wav`.

## 🛠️ Технологический стек

* **Язык программирования:** C++17
* **Фреймворк UI:** Qt 6 (Widgets)
* **Платформа:** Windows Only (активно используются оптимизированные WinAPI вызовы):
  * `Serial Overlapped I/O` — для асинхронного, непотокового обмена данными по COM-порту.
  * `WinMM (Windows Multimedia API)` — для захвата, воспроизведения и записи звука без лишних слоев абстракции.
  * `DWM (Desktop Window Manager)` — для кастомизации и плавной отрисовки интерфейса.

## 🛰️ Спецификация CAT-протокола

Приложение взаимодействует с микроконтроллером посредством текстовых Kenwood-подобных команд. Каждая команда должна завершаться точкой с запятой (`;`). 

> 💡 **Примечание:** Запрос без параметра (например, `FA;`) возвращает текущее значение из приёмника. Ответ `?` расценивается приложением как ошибка CAT-команды.

| Команда | Назначение | Формат / Пример | Описание |
| :--- | :--- | :--- | :--- |
| **FA** | Частота VFO A | `FA00003600000;` | 11 цифр, значение в Гц (в примере: 3.6 МГц) |
| **MD** | Режим модуляции | `MD2;` | `1`=LSB, `2`=USB, `3`=CW, `4`=FM, `5`=AM |
| **SL** | Нижний срез фильтра | `SL0300;` | 4 цифры, значение в Гц |
| **SH** | Верхний срез фильтра | `SH2700;` | 4 цифры, значение в Гц |
| **NR** | Шумоподавление | `NR1;` / `NR0;` | `1` — включено, `0` — выключено |
| **NT** | Режекторный нотч-фильтр | `NT1;` / `NT0;` | `1` — включено, `0` — выключено |

## 🚀 Сборка и Запуск

### Требования
* ОС Windows 10 / 11
* MSVC Compiler (с поддержкой C++17)
* Qt SDK 6.x
* CMake 3.16+

### Компиляция через CLI
1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com
   cd rp2040-receiver-control
   ```
2. Создайте директорию сборки и скомпилируйте проект:
   ```bash
   mkdir build && cd build
   cmake -DCMAKE_PREFIX_PATH="C:/Qt/6.x.x/msvc2019_64" ..
   cmake --build . --config Release
   ```
